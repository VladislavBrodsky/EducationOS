# Preserved earlier learner interface

This unmounted single-page learner interface, its local model and original tests
are preserved for historical continuity with the reconstructed v0.5 work. The
active website and learner experience live in `src/app/` and
`src/components/demo/`; their browser-only synthetic draft presentation is in
`src/lib/demo-state.ts`. Python owns the application/API learning service.

This archive is excluded from the active TypeScript build and checks. Its
older experiment materials, measurement model and assumptions are historical;
do not deploy it independently. Preserve original imports for source review.
