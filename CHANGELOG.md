Earlier versions describe recovered documentation or conversation records, not verified Git tags or deployed releases.

## 0.5.0 — 2026-10-18

Presentation foundation and reconstruction of the recorded v0.4 demonstration:

- Next.js App Router, React, and TypeScript presentation shell.
- Shared accessible SVG/Lucide components, editorial guardian view, lime learner visuals, and a frontend emoji check.
- Five age bands, a seven-step TRIZ Inventors Lab with three distinct ideas, manual fair-test comparisons, Skills Vault, JSON portfolio export, and session reset.
- Portfolio evidence excludes unsubmitted or reopened steps; editing an earlier step invalidates subsequent completion.
- Synthetic browser-memory state only; real enrollment and protected intake disabled.
- Browser journey, keyboard, responsive layout, automated axe checks, unit tests, CI, and provenance documentation.
- Applied the user's later architecture correction: **Python/FastAPI owns backend/API/domain/authentication, with SQLAlchemy/Alembic and PostgreSQL.** Next.js/TypeScript owns presentation. The completed TypeScript backend, SQL, and policy tests are preserved only as [superseded reference](reference/typescript-backend/README.md).
- Active Next.js `/api/v1` handlers return no-store HTTP 503 pending the canonical FastAPI integration. No active Node core backend or live database migration is delivered by this handoff.

Results and remaining verification are in [TESTING.md](docs/TESTING.md). Reference-backend tests do not certify the canonical Python implementation. This release is not production-safe for child enrollment and has no independent safety or accessibility certification.
