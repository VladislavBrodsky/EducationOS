# Magic UI adaptations

Source: https://github.com/magicuidesign/magicui and https://magicui.design/docs/components, inspected 25 October 2026. Copyright (c) Magic UI. The MIT license is included in `LICENSE`.

`orbiting-circles.tsx`, `shine-border.tsx`, and `bento-grid.tsx` adapt the official registry component structure. `magic-card.tsx` adapts the pointer-coordinate spotlight pattern. Styles and APIs are changed for EducationOS's ink/lime palette, semantic links, local rendering, reduced motion, and explicit animation pause. Motion and theme-provider dependencies were replaced with scoped CSS and small React interactions. The bento content, paper bridge model, copy, and science artwork belong to EducationOS.

References: [Bento Grid](https://magicui.design/docs/components/bento-grid), [Magic Card](https://magicui.design/docs/components/magic-card), [Orbiting Circles](https://magicui.design/docs/components/orbiting-circles), [Shine Border](https://magicui.design/docs/components/shine-border). The button glint and single-entry transition are custom CSS/browser implementations informed by [Shimmer Button](https://magicui.design/docs/components/shimmer-button) and [Blur Fade](https://magicui.design/docs/components/blur-fade).

No premium templates, reference illustrations, testimonial identities, or reference marketing claims were copied.

`progressive-blur.tsx` adapts the layered backdrop-filter and gradient-mask approach from the [official Progressive Blur registry](https://magicui.design/r/progressive-blur.json), inspected 28 October 2026. It adds horizontal edges, uses five restrained blur layers, and keeps the overlays outside the scroll viewport so they remain fixed and never intercept input. The reusable subject rail adds icons, explicit pause and direction controls, automatic overflow-only scrolling, reduced-motion support, and suspension while the reader hovers, focuses, touches or manually scrolls the list.

## Motion and component studio — 30 October 2026

The complete official catalog is indexed in `src/lib/magic-ui-catalog.ts`, with 77 references and source URLs verified against upstream commit `efe76fc5755eca1142dd4f74c1d6f0ace2887e3c`. The component studio distinguishes 16 working EducationOS previews from official reference links; a catalog reference is not an installed component. Paid Pro templates are excluded.

New lightweight adaptations are informed by the official [Marquee](https://magicui.design/docs/components/marquee), [Word Rotate](https://magicui.design/docs/components/word-rotate), [Scroll Progress](https://magicui.design/docs/components/scroll-progress), [Animated List](https://magicui.design/docs/components/animated-list), [Blur Fade](https://magicui.design/docs/components/blur-fade), [Ripple Button](https://magicui.design/docs/components/ripple-button), [Interactive Hover Button](https://magicui.design/docs/components/interactive-hover-button), [Terminal](https://magicui.design/docs/components/terminal), [Dot Pattern](https://magicui.design/docs/components/dot-pattern), and [Grid Pattern](https://magicui.design/docs/components/grid-pattern). The Shimmer Button preview uses the established custom button-glint style. CSS gradients replace upstream SVG pattern geometry, and the Terminal is a static educational code example rather than a command runner. APIs differ from upstream deliberately.

React, scoped CSS, IntersectionObserver and the Web Animations API replace optional upstream animation dependencies. Server/no-JavaScript content stays visible and static; looping controls appear only after hydration. Duplicate marquee artwork is inert and hidden from assistive technology, while real topic choices remain in a separate original control list. Reduced motion, focus/hover, visibility and the page pause setting suspend decorative movement. No external sample avatars, posts, stock photos or fabricated testimonials are loaded.
