EducationOS v0.5.0 adds a working learner dashboard and seven-step TRIZ Inventors Lab with five age bands, three-idea exploration, fair-test comparisons, an evidence-linked Skills Vault, JSON portfolio export, and session reset. Shared accessible SVG/Lucide components provide lime learner visuals and an editorial guardian preview; frontend emojis are prohibited.

Python/FastAPI remains the canonical backend/API/domain/authentication architecture, using SQLAlchemy/Alembic with PostgreSQL. This PR delivers the Next.js/React/TypeScript presentation handoff. Its API handlers return unconditional no-store HTTP 503 while canonical integration proceeds. The superseded TypeScript backend, SQL migration, and policy tests are preserved under `reference/typescript-backend` as review material, excluded from the active app. Their tests do not validate the Python backend.

The demo uses fictional notes in browser memory, sends no learner notes to an API, and clears work on refresh/reset. Real enrollment remains disabled. Identity/consent integration, privacy operations, curriculum review, independent security/accessibility review, and safeguarding remain release gates; this is not production-safe for child enrollment.
